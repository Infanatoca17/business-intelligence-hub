# Synthetic data contract

Every business record is generated by `scripts/generate-data.mjs`; it does not read the supplied reference archives. The generated bundle is committed at `src/data/atlas-bundle.json`. IDs are new identifiers with `ATL-` prefixes. There are no nulls, empty field values, missing-data labels, original identifiers, or real personal contact addresses.

| Dataset | Rows | Key | Relationship and contents |
|---|---:|---|---|
| programs | 4 | id | Ordered program names, color, description, and three teams per program |
| projects | 48 | id | programId, locationId, planId, owner, dates, objective, outcome, schedule, budget and calculated metrics |
| deliverables | 288 | id | projectId; six deliverables per project; completion, status, assignee, due date, budget |
| plans | 48 | id | projectId; response approach, owner, review dates and status |
| risks | 144 | id | projectId and planId; 96 risks and 48 issues; score inputs, owner, actions and deadlines |
| staff | 96 | id | projectId; unique fictional person, role, .example email, FTE and weekly hours |
| financials | 48 | id | projectId; budget, expenditure, forecast and next-year budget in USD |
| funding | 24 | id | projectId; fictional donor, stage, probability, requested amount and decision date |
| locations | 24 | id | fictional site names, illustrative coordinates, public country names and fictional office assignments |

All downstream dataset rows refer to an existing project. Each project's location and plan references resolve. Every project has six deliverables, three threat records, two staff records, one financial record and one plan. Funding opportunities exist for half the projects; an empty project funding table means there is no additional opportunity, not that an existing field is missing.

Geographic land boundaries are static public reference data from `world-atlas` / Natural Earth. The generator places fictional sites near representative regional coordinates; these are not operational locations. See the third-party notices.

Do not replace this JSON with an organizational reporting file. Extend the generator and its validation tests to add more demonstration scenarios.
